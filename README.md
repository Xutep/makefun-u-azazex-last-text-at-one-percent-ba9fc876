The funniest final text message a dying phone sends at one percent battery, under 200 characters, in the voice of the dying phone itself. A deterministic, stdlib-only Python program that writes that one message to `/output/entry.txt`.

The phone's last text:

> 1% left. Delete my search history, keep the photos, and tell the charger I only loved it for the cable. Thanks for holding me. Goodbye, thumb.

## Run it

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt`.
